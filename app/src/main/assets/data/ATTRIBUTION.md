`tr-cities.js` içindeki veri, [cihadturhan/tr-geojson](https://github.com/cihadturhan/tr-geojson) deposunun `1866ee63439a05681c4941cb91c2ec64555b5e6d` revizyonundan alınmıştır. Kaynak JSON SHA-256: `5034488aa6c0fcbca6b69a02e1c1c0f40bf9294a1fdbd7c6d2b48ebbbac8884b`. Tek dönüşüm, WebView içinde yerel betik olarak yüklemek için `window.PROVINCE_GEOJSON=` atamasıyla sarılmasıdır.

Kaynak, sınırların OpenStreetMap verilerinden üretildiğini ve [Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/) kapsamında olduğunu bildirir. Uygulama haritasında OpenStreetMap katkıda bulunanlara atıf gösterilir. Veri değiştirilmeden paketlenmiştir.
